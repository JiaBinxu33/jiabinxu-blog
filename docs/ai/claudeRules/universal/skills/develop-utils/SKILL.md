# 工具方法开发

## 概述

这个 skill 用于工具方法开发场景，支持检索现有工具方法和新增自定义工具方法。

**核心能力**：
- 分析工具方法需求
- 优先检索已有方法，禁止重复造轮子
- 新增自定义工具方法

## 工作流程

请严格根据以下工作流程制定 TODOList 并分步骤执行，禁止遗漏步骤，如果有不确认的地方请咨询用户

### 步骤1: 分析方法需求

根据用户输入总结工具方法需求，包含：
- 方法名称
- 方法功能描述
- 输入参数
- 返回值类型

**检索结果处理**：

- **不存在**：继续步骤3

### 步骤3: 查询第三方库

在常用第三方库（如 `lodash`、`dayjs`、`qs` 等）中查找是否已有对应方法。

**检索结果处理**：
- **已存在**：返回该第三方库方法的使用方式，流程结束
- **不存在**：继续步骤4，新增自定义工具方法

### 步骤5: 新增工具方法

在确认目录下新增工具方法，遵循以下规范：

**文件命名**：使用小驼峰，如 `formatDate.ts`

```typescript
/**
 * 方法名称
 * @description 方法功能描述
 * @param paramName - 参数描述
 * @returns 返回值描述
 */
export const methodName = (params: ParamType): ReturnType => {
  // 实现逻辑
};
```

**注意事项**：
- 添加完整的 JSDoc 注释
- 添加健壮的错误处理
- 考虑边界情况（null / undefined / 空字符串）
