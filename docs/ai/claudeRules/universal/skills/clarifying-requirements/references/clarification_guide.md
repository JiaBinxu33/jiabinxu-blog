# 需求澄清指南

## 提问方向指引

**确定边界范围**
- 这个功能包含哪些具体操作？
- 明确不包含什么？
- 与现有功能如何配合？

**验证理解**
- 我的理解是否正确？
- 还有哪些细节需要考虑？
- 有没有遗漏的场景？

### 结合代码理解的澄清策略

**基于现有代码提问**
- 看到现有的X组件，新需求是要扩展它还是独立开发？
- 现在的路由结构是这样的，新功能放在哪个路由下？
- 我注意到现有的状态管理方式，新功能需要类似的处理吗？
- 现有的UI组件库中有可复用的吗？

**技术实现澄清**
- 这个功能是新增页面还是在现有页面上扩展？
- 需要调用哪些API接口？
- 有什么性能或响应时间要求？
- 需要支持哪些设备和浏览器？
