    # MarkDown文档书写规则

    # 锚点链接的通用转换规则

    大多数 Markdown 解析器（如 GitHub、VS Code、Obsidian、Typora 等）遵循以下规则来生成锚点：

    1. 空格变连字符： 所有的空格都要替换为 -。
    2. 全部小写： 如果标题中有英文，需全部转换为小写（中文保持不变）。
    3. 移除特殊符号： 标点符号（如 ?、!、，、。、（）、()）通常会被直接删掉，不留痕迹。
    4. 保留中文字符： 现代解析器都能完美支持中文锚点。
